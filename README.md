# Савелий — кот-репетитор английского

Сайт для изучения английских слов. Ученик проходит тест на уровень, получает
персональный словарь, тренирует его на 27 упражнениях и играх и болтает с котом.
У репетитора — своя панель с прогрессом каждого ученика.

## Два режима

**Витрина (GitHub Pages).** Открывается без сервера: тест, словарь, все
тренировки, награды, голос. Прогресс живёт только в браузере ученика —
панели репетитора, домашки и синхронизации между устройствами тут нет.

**Полная версия (свой сервер).** Всё то же плюс база учеников, панель
репетитора, группы, домашка и отчёты родителям.

## Запуск на своём компьютере

```bash
python3 server.py
```

Ученик — http://localhost:4210, панель — http://localhost:4210/tutor.html
Ничего доустанавливать не нужно: только Python 3.

## Установка на обычный хостинг (Timeweb и др.)

Если хостинг с местом под сайт уже есть — VPS не нужен. Требуется тариф
с Python и mod_wsgi. Пошагово: [deploy/TIMEWEB.md](deploy/TIMEWEB.md).

## Установка на свой сервер (VPS)

На чистом Ubuntu/Debian от root:

```bash
git clone https://github.com/gladkihsava21-hash/english-cat.git
bash english-cat/deploy/install.sh ваш-домен.ru почта@для-ssl.ru
```

Скрипт ставит Python, nginx и сертификат Let's Encrypt, заводит службу
`savely` и включает автозапуск. Домен к этому моменту должен уже смотреть
на IP сервера, иначе сертификат не выпустится.

Обновление после правок:

```bash
bash /opt/savely/deploy/update.sh
```

Полезное:

| Зачем | Команда |
| --- | --- |
| Логи | `journalctl -u savely -f` |
| Перезапуск | `systemctl restart savely` |
| Резервная копия базы | `bash tools/daily-backup.sh` — через `cp` НЕЛЬЗЯ, база в режиме WAL |

База лежит в `/var/lib/savely/` — вне папки с кодом, чтобы обновление
не могло задеть прогресс учеников.

## Мозг кота

По умолчанию Савелий отвечает по заготовленным правилам — этого хватает
для словаря и тренировок. Умный чат подключается двумя способами:

- **Локально** — через `claude -p` от подписки. Нужно один раз выполнить
  `/login` в терминальном `claude`.
- **На сервере** — через Claude API: положить ключ в `ANTHROPIC_API_KEY`.

## Версия статики

Никогда не правьте `?v=` руками — версия живёт в пяти местах (три html,
`sw.js` и `server.py`), и руками они разъезжаются. Есть скрипт:

```bash
python3 tools/bump.py
```

Он поднимает `?v=` на страницах, пересобирает список офлайн-кэша из самих
страниц и пишет ту же цифру в `ASSET_VERSION`.

## Если сайт упал (памятка владельцу, без программиста)

1. Открой `https://wordcat.ru/health`. Отвечает `{"ok": true, ...}` —
   сервер жив, проблема скорее у жалующегося (интернет, кэш: Ctrl+Shift+R).
2. Не отвечает или ошибка — панель Timeweb → «Сайты» → kotsaveli →
   **«Перезапустить приложение»**. Это чинит 9 из 10 случаев.
3. Не помогло — там же «Логи» → error.log, последние строки; и загляни
   в админку сайта, раздел «Ошибки сервера» (если открывается).
4. Совсем плохо — восстановись из копии: копии лежат в `~/savely-backups/`
   (ежедневные) и в `~/kotsaveli/savely-data/pre-deploy-*.db` (перед каждым
   обновлением). Свежую делает `bash ~/savely-backup.sh kotsaveli`.
5. Домен/SSL истёк — «Домены и SSL» в панели: продлить, перевыпустить.

Сайт не трогает базу при перезапуске: прогресс учеников от пунктов 1–2
не страдает.

## Если данные утекли (памятка владельцу, 24 часа)

Утечка — это не только взлом. Сюда же: база или папка с фотографиями
тетрадей оказалась доступна снаружи; кто-то посторонний получил пароль
от админки или от панели хостинга; резервная копия ушла не туда; ошибка
в коде показала одному ученику данные другого.

По 152-ФЗ (ч. 3.1 ст. 21) оператор обязан **в течение 24 часов** с момента
обнаружения уведомить Роскомнадзор о факте инцидента, и **в течение 72
часов** — о результатах внутреннего расследования. Считается от момента,
когда узнал, а не когда утечка случилась.

**Первые полчаса — остановить утечку.**

1. Панель Timeweb → «Сайты» → kotsaveli → **остановить приложение**, если
   утечка идёт прямо сейчас. Сайт полежит час — это дешевле, чем ещё сутки
   утечки.
2. Сменить пароли: админка (`savely-data/admin.txt`), панель хостинга,
   SSH-ключ, почтовый ящик support@. Если утёк ключ Яндекса —
   отозвать в консоли Yandex Cloud.
3. Сделать копию базы и логов **до** любых починок: `bash ~/savely-backup.sh
   kotsaveli`, плюс скачать `error.log` из панели. Это материал
   расследования, без него потом нечего показать.

**В тот же день — уведомить.**

4. Форма на `pd.rkn.gov.ru`, раздел об инцидентах. Что понадобится:
   когда обнаружил, что именно утекло (категории данных, сколько
   субъектов), предполагаемая причина, какие меры приняты. Черновик
   реквизитов оператора — в `deploy/RKN.md`.
5. Посчитать масштаб по базе, не на глаз:

   ```bash
   ssh savely "python3 -c \"
   import sqlite3
   c = sqlite3.connect('/home/c/cp698704/kotsaveli/savely-data/savely.db')
   print('репетиторов:', c.execute('select count(*) from tutors').fetchone()[0])
   print('учеников:', c.execute('select count(*) from students').fetchone()[0])
   print('фото тетрадей:', c.execute('select count(*) from photo_homework').fetchone()[0])
   \""
   ```

**В течение 72 часов — результаты расследования.** Что нашли, как
закрыли, что сделали, чтобы не повторилось.

**Кого предупредить своими словами.** Закон прямо не обязывает извещать
каждого субъекта, но здесь данные детей: репетиторам и родителям лучше
написать самому и раньше, чем они узнают со стороны.

Чего НЕ делать: молча чинить и надеяться, что не заметят. Штраф за
несообщение больше, чем за саму утечку, а при повторном нарушении
считается уже оборотный.

## Как понять, что обновление реально доехало

```bash
curl https://ваш-домен/health
```

Отдаёт `{"ok": true, "version": N}`, где N — версия кода, **который сейчас
в памяти процесса**. На виртуальном хостинге питон живёт внутри процесса
веб-сервера, и заливка файлов сама по себе ничего не перезапускает:
страницы обновятся, а `server.py` останется старый. Совпало с `?v=` на
странице — всё доехало; не совпало — нажмите «Перезапустить приложение»
в панели хостинга.

### Если /health показывает не ту цифру

Версия в `/health` берётся из `ASSET_VERSION` в `server.py`. Если этот файл
не попал в коммит (например, над ним параллельно работает кто-то ещё),
цифра отстанет от страниц, и проверка перестанет отвечать на свой вопрос.
Тогда доехало ли обновление, можно выяснить сверкой содержимого:

```bash
for f in index.html tutor.html sw.js server.py db.py; do
  g=$(git show HEAD:$f | shasum -a 256 | cut -c1-12)
  p=$(ssh savely "shasum -a 256 ~/kotsaveli/public_html/$f" | cut -c1-12)
  [ "$g" = "$p" ] && echo "$f совпадает" || echo "$f РАЗЛИЧАЕТСЯ"
done
```

Совпало — файлы на месте. Но это говорит только о диске: питон живёт внутри
процесса веб-сервера и может держать в памяти прежний код. Перезапуск
вызывает изменение `wsgi.py` — проверить можно его временем правки:

```bash
ssh savely "ls -l --time-style=+%H:%M ~/kotsaveli/public_html/wsgi.py"
```

Свежее время — выкладка тронула файл, приложение перечитано. Не уверен —
жми «Перезапустить приложение» в панели, это безвредно.

## Что грузится когда

Словарь — это 326 КБ по проводу, и раньше их качали все подряд, включая
человека на экране приветствия. Теперь:

- **экран приветствия и вход в панель** — без словаря вообще;
- **вернувшийся ученик** — главная рисуется сразу, словарь едет следом;
- **новый ученик** — словарь приезжает по нажатию «Поехали, 36 слов»;
- **выражения** — только когда открывают их раздел или одно из трёх
  упражнений на выражения.

Всё это через `ensureWords()` / `ensurePhrases()` в `js/util.js`. Если
добавите ещё один файл, который грузится кодом, а не тегом на странице,
впишите его в `LAZY` в `tools/bump.py` — иначе он не попадёт в офлайн-кэш.

## Ограничение частоты запросов

Счётчик лежит в базе (таблица `rate_hits`), а не в памяти процесса. Это
принципиально: на виртуальном хостинге запросы обслуживает не один
процесс, у каждого свой словарь в памяти, и общего лимита не получается
вовсе. Проверять лимиты нужно на боевом — локальный однопроцессный
сервер эту разницу скрывает.

## Шрифты

Лежат в `css/fonts/`, подключены через `css/fonts.css`. Обновить:

```bash
python3 tools/fetch_fonts.py
```

Имена файлов не версионируются, а кэш у них годовой — если понадобится
заменить начертание, файл придётся переименовать.
