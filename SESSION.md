## Найдено самим — этого не было ни в одном отчёте

Самая ценная часть сессии. Каждая из этих штук работала неправильно
месяцами и не была никем замечена.

| Что | Как проявлялось |
|---|---|
| **Лимит частоты не работал НИКОГДА** | Счётчик жил в памяти процесса, а на хостинге их много. Перенесён в базу. На боевом: 10 прошло, 5 отбито |
| **Офлайн не работал ни разу** | `caches.match` сверял адрес вместе с `?v=`, совпадений не было, вместо кода браузер получал разметку — белый экран |
| **Домашка пропадала** после каждой перезагрузки страницы | Переменная стартовала пустой, а перерисовка шла только при изменении задания |
| **Старое сохранение роняло главный экран** | В миграции не хватало `dictionary` и `recommendSeen` |
| **`vocabEstimate` тоже не был в миграции** | Кот говорил «запас ~undefined слов». Поймано новым `tools/validate-state.py` |
| **У B2 пять карточек из шести полупустые** | Рекомендации брались из импорта, где нет примера и категории |
| **Ловушки из импорта** | К слову `save` шла «оценка налогообложения» |
| **Ни у панели, ни у главной не было `<h1>`** | Для программы чтения — страница без названия |
| **Кот закрывал конец длинной страницы** | На кроссворде под ним оказывались две подсказки |
| **Совет по бэкапу давал пустой файл** | `cp savely.db` при WAL: свежие записи в `savely.db-wal` |
| **Ключа Claude API на сервере нет** | Проверка фото и умный чат не работают, см. «Что дальше» |

Плюс один баг я **сделал сам** и сам же нашёл: перевод фокуса на
заголовок рисовал зелёную рамку вокруг него. `outline: none` не хватило —
общее правило в `savely.css` рисует кольцо через `box-shadow`.

## Решения, которые стоит знать

Здесь я спорил с заданием. Если новая модель захочет «исправить обратно» —
сначала прочитать причину.

**Возврат денег.** Просили «деньги не возвращаем». Написал иначе: единица
услуги — календарный месяц, начатый не пересчитывается, оплаченные вперёд
и не начатые возвращаются. Прямой запрет ничтожен по статье 32 ЗоЗПП —
суд его не применит, а сам пункт в договоре это отдельное нарушение.

**Домашний адрес в политике.** Дали полный, с квартирой. Опубликовал
только область и город, точный адрес — по запросу на почту. Плюс
`noindex`. Домашний адрес несовершеннолетнего на общедоступной странице
детского сайта — лишнее.

**Preload словаря (пункт 4 задания).** Сделал аккуратно, не preload,
а `load` + `requestIdleCallback`. Замерил на боевом:

```
оценка              93 → 79
главный элемент     2,6 → 4,7 с
вес первого экрана  349 → 674 КБ
```

Откатил. Причина глубже способа: на экране приветствия словарь не нужен
вообще, и большинство до теста не доходят. Комментарий с цифрами оставлен
на месте функции, чтобы следующий не пошёл по кругу.

**Streaks (пункт 6 задания) — уже были сделаны.** Считаются из истории
занятий, а не хранятся полями `lastVisit`/`streak`. Это лучше: нечему
рассинхронизироваться и не нужна миграция. Делать как в задании — регресс.

**Аналитика в панели (пункт 7) — почти вся есть.** «Учеников»,
«Занимались за неделю», «Не заходили 7+ дней», «Выучено слов», по
каждому ученику — уровень, выучено, очки, награды, полоска занятий за
4 недели.

**Чат без ключа (пункт 3) — не мёртвый.** Есть правиловый мозг: предлагает
слова, проверяет, показывает статистику. Прятать кнопку значит убрать
работающее. Нужна честная рамка, а не заглушка.

**Wikimedia в панели (пункт 8) — под вопросом.** Фотографии под CC BY,
лицензия требует указывать автора. Цепочку атрибуции держит
`tools/build_images.py` → `credits.html`. Ручная привязка её рвёт —
получим нарушение лицензии на детском сайте. Обсудить с владельцем.

## Как проверять (коротко; подробно в AGENTS.md)

```bash
python3 server.py                 # локально, порт 4210
python3 tools/bump.py             # ОБЯЗАТЕЛЬНО перед выкладкой
curl https://wordcat.ru/health    # версия ИЗ ПАМЯТИ процесса
```

Панель предпросмотра в этой среде **врёт**: за сессию схлопывалась в
нулевую ширину, не перерисовывала статику, не доставляла нажатия клавиш.
Мерить DOM (`getBoundingClientRect`, `getComputedStyle`), снимки —
настоящим Chrome:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --no-sandbox --disable-gpu --hide-scrollbars \
  --window-size=900,1400 --screenshot=out.png \
  --virtual-time-budget=4500 "http://localhost:4210/index.html"
```

Перед проверкой снимать service worker, иначе увидите старый код:

```js
navigator.serviceWorker.getRegistrations().then(rs => rs.forEach(r => r.unregister()));
caches.keys().then(ks => ks.forEach(k => caches.delete(k)));
```
