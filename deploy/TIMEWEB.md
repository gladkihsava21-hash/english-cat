# Установка на виртуальный хостинг Timeweb

Подходит, если у тебя уже есть хостинг с местом под сайт. Покупать VPS не нужно.
Нужен только домен и поддержка Python на тарифе.

## Что должно быть на тарифе

- **Python 3.10+** и **mod_wsgi** (раздел «Приложения» в панели)
- **Доступ по SSH**
- Бесплатный SSL-сертификат Let's Encrypt — включается в панели в один клик

Если Python на тарифе нет — это единственный случай, когда придётся брать VPS,
тогда смотри `deploy/install.sh`.

## Шаги

**1. Привязать домен.** Панель Timeweb → «Домены» → добавить домен и указать
его для сайта. Дождаться, пока он заработает по HTTP.

**2. Включить SSL.** Панель → «SSL-сертификаты» → выпустить бесплатный
Let's Encrypt для домена. Без HTTPS не работают микрофон (голосовой чат)
и установка сайта на телефон.

**3. Залить код.** По SSH:

```bash
cd ~
git clone https://github.com/gladkihsava21-hash/english-cat.git tmp-savely
mv tmp-savely/* tmp-savely/.htaccess ТВОЙ-ДОМЕН.ru/public_html/
rm -rf tmp-savely
```

Точный путь к папке сайта виден в панели — обычно
`/home/логин/ТВОЙ-ДОМЕН.ru/public_html`.

**4. Указать точку входа.** Панель → «Приложения» (или «Python») → создать
приложение:

- тип: **WSGI**
- файл запуска: **wsgi.py**
- callable: **application**

**5. Проверить.** Открыть `https://ТВОЙ-ДОМЕН.ru/health` — должно вернуться
`{"ok": true}`. Дальше сайт ученика на главной, панель — `/tutor.html`.

## Где лежат данные

База создаётся сама в `~/savely-data/savely.db` — **на уровень выше**
публичной папки. Это принципиально: внутри `public_html` Apache отдал бы
её по прямой ссылке вместе с хешами паролей и токенами репетитора.

Резервная копия:

```bash
cp ~/savely-data/savely.db ~/savely-backup-$(date +%F).db
```

Делай её перед каждым обновлением — файл маленький, места не жалко.

## Обновление сайта

```bash
cd ~/ТВОЙ-ДОМЕН.ru/public_html && git pull
```

Если заливал без git — просто перезалей файлы, кроме `~/savely-data/`.
После обновления в панели нажать «Перезапустить приложение».

## Если что-то не работает

| Симптом | Причина |
| --- | --- |
| 500 на всех страницах | Не выбран callable `application` или не тот файл запуска |
| Панель репетитора пустая | Приложение не запущено — проверь `/health` |
| Стили поехали | Старый кэш: нажать Ctrl+Shift+R |
| «Не защищено» в браузере | Не выпущен SSL |

Логи ошибок — в панели, раздел «Логи», файл `error.log`.

## Чего на виртуальном хостинге не будет

Умный чат через подписку (`claude -p`) работает только на своём компьютере —
на хостинге нет ни CLI, ни авторизации. Савелий будет отвечать по правилам.
Чтобы включить полноценный ИИ, нужен ключ Claude API в переменной
`ANTHROPIC_API_KEY`.
