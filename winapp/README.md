# Савелий — приложение для Windows

Два способа получить «Савелия» программой на Windows.

## Способ 1 (рекомендуемый, ничего собирать не надо): PWA

Сайт wordcat.ru — полноценное PWA: офлайн, свой значок, своё окно.

1. Открой **wordcat.ru** в Edge или Chrome.
2. В адресной строке справа — значок «Установить» (или меню ⋯ →
   «Приложения» → «Установить Савелий»). В профиле ученика
   («Мой профиль») есть и своя карточка «Установить приложение».
3. Готово: «Савелий» в меню «Пуск», на панели задач, работает без
   интернета (прогресс доедет на сервер, когда сеть появится).
   Правый клик по значку — ярлыки: Тренировки, Словарь, Чат.

Это тот же сайт: обновления приезжают сами, ничего перевыпускать не нужно.

## Способ 2: Savely.exe (когда нужен именно файл-программа)

Тонкая оболочка: окно + WebView2 (движок Edge, предустановлен в Windows
10/11). Весь продукт по-прежнему сайт — оболочку обновлять не нужно.

Сборка (на Windows-машине, один раз):

1. Поставь **.NET 8 SDK** с https://dot.net/download (бесплатно, кнопка
   «Download» → установщик → далее-далее).
2. Открой PowerShell в этой папке (`winapp`) и запусти:
   `powershell -ExecutionPolicy Bypass -File build.ps1`
3. Готовый `bin\Savely.exe` (~2 МБ + рантайм) можно копировать куда угодно.

Файлы:
- `Program.cs` — окно приложения (портретная рамка, заголовок из страницы,
  внешние ссылки уходят в браузер);
- `Savely.csproj` — проект (единственная зависимость — пакет WebView2);
- `build.ps1` — сборка одним файлом;
- `icon.ico` — значок (собран из icon-512.png сайта).

Замечание для сопровождения: это отдельный артефакт, а не часть продукта —
в основной кодовой базе по-прежнему нет ни сборщика, ни зависимостей
(см. AGENTS.md §2). Приложение не хранит ничего своего: все данные — у
сайта, в его service worker и на сервере.
