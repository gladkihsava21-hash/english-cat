# Савелий — приложение для macOS

Тонкая оболочка над wordcat.ru: окно + WKWebView (движок Safari уже в
системе). Весь продукт — сайт: service worker, офлайн и обновления
работают сами, приложение перевыпускать не нужно. Камера и микрофон
разрешены для видеоуроков (системный диалог спросит один раз).

## Собрать (на этом Mac, одна команда)

```bash
cd macapp && bash build.sh
```

Нужен только `swiftc` из Command Line Tools (`xcode-select --install`).
Получится `macapp/Savely.app` — перетащи в «Программы» или в Dock.

Первый запуск: macOS может спросить про камеру/микрофон на первом
видеоуроке — это нормально, отвечай «Разрешить».

## Замечание для сопровождения

Как и winapp/, это отдельный артефакт, а не часть продукта: в основной
кодовой базе нет ни сборщика, ни зависимостей (AGENTS.md §2). Собранный
`Savely.app` в git не кладём (в .gitignore).

Файлы: `Savely.swift` — окно и правила (внешние ссылки — в браузер,
заголовок из страницы, медиа-разрешения только для wordcat.ru),
`Info.plist` — описания доступа к камере/микрофону, `build.sh` — сборка
(swiftc + iconutil).
